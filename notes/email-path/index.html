Note 01 / 邮件基础

一封邮件，如何找到收件服务器？

邮箱地址中，@ 后面的部分不仅是一段名称，也是查找投递目的地的线索。发送方通常先查询这个域名的 MX 记录，再连接相应的邮件服务器。

01 / 域名告诉邮件往哪里走

MX 记录给出接收邮件的主机名；主机名再通过 A 或 AAAA 记录解析为 IP 地址。网站和邮箱可以使用不同服务器，因此“网站可以打开”和“邮件可以送达”是两项不同的检查。

02 / SMTP 负责交接

连接建立后，发送方通过 SMTP 提交信封发件人、收件人和邮件内容。服务器接受内容后，邮件仍可能需要经过队列与本地投递，才能进入最终存储。

“服务器接受了邮件”与“邮件已经完整保存”应分别验证。测试时可以同时检查正文、HTML、附件以及实际收件记录。

03 / 正文之外还有线索

Received 等邮件头记录部分传输信息，但上游提供的内容不应一概信任。实际连接 IP、接收时间和本机日志能补充观察依据。

进一步阅读：RFC 5321 — SMTP。
