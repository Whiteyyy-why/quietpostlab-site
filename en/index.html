Note 02 / Dataset practice

Small notes on
email datasets.

A useful collection is more than a message count. Where a message came from, how often it repeats, and why it was labeled all affect what we can learn from it.

Keep the source context

Preserve the received message and its envelope information. Record the collection channel and arrival time so that later analysis can distinguish changes in content from changes in sampling.

Count patterns, not just copies

A bulk campaign can produce many nearly identical messages. Exact hashes identify identical files; similar templates need additional comparison. Keep originals while recording duplicate groups separately.

Receiving a message at an experimental address does not by itself prove that it is spam. Legitimate questions, mistakes and automated notices require separate review.

Evaluate beyond the collection

Separate related campaigns when preparing training and test data. Evaluate against representative normal messages as well, so that apparent gains do not hide an increase in false positives.
